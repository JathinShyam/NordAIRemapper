# Nord AI Remapper — Design kit

## Typography (v2)

| Role | Font | Why |
|---|---|---|
| **Headings** | [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) | Geometric, slightly technical — clear hierarchy on dark product UI |
| **Body / UI** | [Inter](https://rsms.me/inter/) | Best screen readability; high x-height for chips, lists, settings |

First letter of headings stays OnePlus red `#EB0028`.

Open [`figma-artboards.html`](./figma-artboards.html) (loads fonts from Google Fonts CDN).

App ships the same OFL files under `app/src/main/res/font/`.
